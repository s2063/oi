# Analyse Documents Metadata | OSINT

[![Logo](<.gitbook/assets/image (1)>)GitHub - ElevenPaths/FOCA: Tool to find metadata and hidden information in the documents.GitHub](https://github.com/ElevenPaths/FOCA)

To run the solution locally the system will need:

* **Microsoft Windows** (64 bits). Versions 7, 8, 8.1 and 10.
* **Microsoft** [**.NET Framework 4.7.1**.](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net471)
* Microsoft [**Visual C++ 2010 x64**](https://www.microsoft.com/en-us/download/details.aspx?id=26999) or greater.
* An instance of [**SQL Server** 2014](https://www.microsoft.com/en-us/download/details.aspx?id=42299) or greater.
